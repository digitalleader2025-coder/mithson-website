# MITHSON BLUE + WHITE THEME

Global palette:
- White: primary surface/background
- Deep blue: primary branding/headings/navigation
- Medium blue: buttons/interactions
- Light blue: secondary surfaces/gradients
- Very dark neutral: only when required for readable text

Forbidden visual theme colors:
gold, yellow, orange, red, purple, green, brown and unrelated accent colors.

All pages and all product pages inherit this same palette.

All Three.js/R3F lighting, materials, environment effects and glow must stay in blue/white.
